## What happened

`aft_inspect` (dead-code + unused-exports categories) flagged 6 exports in
`pi-subagents/src/` as having zero production callers. Each had only one or
two test-only references that existed solely to test the function itself.

## Root cause

The 6 functions accumulated as internal helpers during earlier GC work
(`GC-2026-044` failure-catalog, `GC-2026-boundary-subagent-control`,
`GC-2026-soft-limit-reminder`, etc.) but were never wired into production
code paths. They were kept alive by their own dedicated tests, which masked
the "no callers" property from naive grep checks.

## Fix

`GC-2026-107` removed all 6:

| File | Symbol |
|---|---|
| `pi-subagents/src/settings.ts:501` | `setNetworkAllowedDefaults` |
| `pi-subagents/src/diagnostic.ts:308` | `readAllDiagnostics` |
| `pi-subagents/src/failure-catalog.ts:827` | `resetFailureCatalogCache` |
| `pi-subagents/src/worktree-lease.ts:311` | `resetLeaseWarnings` |
| `pi-subagents/src/usage.ts:48` | `getSessionTokens` |
| `pi-subagents/src/worktree-ownership.ts:167` | `readWorktreeGitdir` |

TDD: red-then-green `pi-subagents/test/dead-exports-removed.test.ts` asserts
each symbol is `undefined` after removal. 6/6 fail at HEAD, 6/6 pass after.

## Follow-ups

- Make `aft_inspect`'s unused-export check a verify-gate (currently a
  category, not a `verify:all` step). Would have caught this earlier.
